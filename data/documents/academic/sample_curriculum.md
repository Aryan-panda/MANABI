# Computer Science Curriculum & Course Catalog

## Core Foundation Courses
- **CS101: Introduction to Computing & Programming (4 Credits)**
  Fundamental programming concepts, control structures, and memory models. No prerequisite.
- **CS201: Data Structures and Algorithms (4 Credits)**
  Stacks, queues, linked lists, trees, graphs, and algorithmic complexity analysis. Prerequisite: CS101.
- **CS202: Database Management Systems (4 Credits)**
  Relational algebra, SQL, normalization, concurrency control, and transaction ACID properties. Prerequisite: CS101.
- **CS204: Computer Networks (4 Credits)**
  OSI model, TCP/IP stack, socket programming, routing protocols, and transport layer security. Prerequisite: CS101.

## Advanced Electives
- **CS301: Distributed Systems (4 Credits)**
  Consensus algorithms (Raft, Paxos), CAP theorem, distributed storage, and RPC architectures. Prerequisites: CS201 and CS204.
- **CS304: Database Internals & Storage Engines (4 Credits)**
  B-Trees, LSM-Trees, write-ahead logging (WAL), buffer pool managers, and query optimization engines. Prerequisite: CS202.
- **CS308: Machine Learning Systems (3 Credits)**
  Supervised and unsupervised learning, model deployment, inference optimization, and vector search systems. Prerequisites: CS201 and MA201 (Linear Algebra & Probability).
